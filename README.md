\# Лабораторная работа № 2.1



\## Скрипты Python для автоматизации управления архитектурой



\*\*Тема:\*\* Анализ логов веб-сервера Nginx, выявление IP-адресов с большим количеством ошибок 404 и отправка уведомлений в Telegram.



\## 1. Цель работы



Изучить исходный Python-скрипт для анализа логов веб-сервера Nginx, ознакомиться с используемыми библиотеками и необходимым программным окружением.



Модифицировать программу таким образом, чтобы она могла анализировать журнал веб-сервера, выявлять подозрительную активность и формировать уведомления.



\## 2. Анализ используемых библиотек



В исходном скрипте используются следующие библиотеки:



\*\*re\*\*



Стандартный модуль Python для работы с регулярными выражениями. Используется для поиска IP-адресов и кодов HTTP-ответов в строках журнала.



\*\*collections.Counter\*\*



Модуль для подсчёта количества повторяющихся элементов. В данной программе используется для определения количества ошибок 404, поступивших с каждого IP-адреса.



\*\*requests\*\*



Внешняя библиотека для выполнения HTTP-запросов. Используется для отправки уведомлений в Telegram через Telegram Bot API.



В модифицированной версии дополнительно используются:



\- \*\*os\*\* — получение настроек Telegram из переменных окружения.

\- \*\*argparse\*\* — обработка параметров командной строки.

\- \*\*pathlib\*\* — проверка существования файлов и работа с путями.



\## 3. Необходимое программное окружение



Для выполнения лабораторной работы использовалось следующее программное обеспечение:



\- Операционная система Windows 11.

\- Python 3.14.

\- Библиотека requests версии 2.34.2.

\- Командная строка Windows (CMD).

\- Текстовый редактор Блокнот.



Установка дополнительной библиотеки выполняется командой:



```bash

python -m pip install requests

```



Для работы с реальными журналами Nginx необходимо иметь доступ к файлу access.log.



Для отправки уведомлений дополнительно требуется создать Telegram-бота и получить его токен и идентификатор чата.



\## 4. Модификация исходного скрипта



В ходе практической части была разработана модифицированная версия исходной программы.



Основные изменения:



1\. Добавлена проверка существования файла журнала.

2\. Улучшен поиск IP-адресов и кодов HTTP-ответов с помощью регулярных выражений.

3\. Добавлен подсчёт ошибок 404 для каждого IP-адреса.

4\. Реализована настройка порога подозрительной активности.

5\. Добавлена обработка ошибок при отправке сообщений в Telegram.

6\. Токен Telegram и идентификатор чата вынесены в переменные окружения.

7\. Добавлена возможность указания пути к журналу через командную строку.



Программа считает IP-адрес подозрительным, если количество ошибок 404 превышает установленный порог.



По умолчанию используется значение 50 ошибок.



\## 5. Практическая реализация



Для проверки работоспособности программы был создан тестовый файл access.log.



В нём содержатся:

\- 51 запрос с IP-адреса 192.168.1.10, каждый из которых завершился ошибкой HTTP 404.

\- Один успешный запрос с IP-адреса 192.168.1.20 с кодом ответа 200.



Для создания тестового журнала использовался отдельный скрипт create\_log.py.



\### Запуск программы



Сначала создаётся тестовый журнал:



```bash

python create\_log.py

```



Затем запускается анализатор:



```bash

python main.py --log access.log --threshold 50

```



\### Полученный результат



В результате выполнения программы был обнаружен IP-адрес 192.168.1.10, с которого поступил 51 запрос с ошибкой 404.



Программа определила превышение установленного порога и вывела сообщение о подозрительной активности.



Отправка уведомления в Telegram не выполнялась, поскольку настройки Telegram-бота не были заданы.
